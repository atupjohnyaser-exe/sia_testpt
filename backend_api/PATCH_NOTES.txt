BOHOL POLICE DEPARTMENT - backend update (includes every earlier patch)

1. Stop php artisan serve (Ctrl + C).
2. Copy the folders app, config, database, routes and tests, plus README.md, over the same ones in your
   backend_api folder. Choose "Replace the files in the destination".
3. Delete the old file config/rockport.php. It is replaced by config/bpd.php.
4. Do NOT replace your .env. The file .env.example is only for reference. Everything new has a default.
5. In backend_api run, one at a time:
     php artisan migrate
     php artisan db:seed --class=PlaceSeeder
     php artisan db:seed --class=OfficerSeeder
     php artisan db:seed --class=BulletinSeeder
     php artisan db:seed --class=ReportSeeder
     php artisan bpd:sync-places
     php artisan optimize:clear
     php artisan serve
   migrate keeps your data. It renames RP- badge and case IDs to BPD- and swaps the old made-up districts
   for real Bohol towns. OfficerSeeder adds the Chief Admin BPD-1000 and sets the five demo accounts back to
   password demo1234. bpd:sync-places needs internet.
6. php artisan test   (turn on pdo_sqlite in php.ini first)
